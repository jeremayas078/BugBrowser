# Bug Browser

Bug Browser to przeglądarka internetowa napisana w Pythonie z wykorzystaniem PySide6 i Qt WebEngine.

**Autor:** Jakub Raś

## Funkcje
- Przeglądanie stron w kartach
- Historia i zakładki
- Pobieranie plików
- Tryb prywatny
- Prosty AdBlock
- Sprawdzanie aktualizacji
- Obsługa motywów jasnego i ciemnego (od wersji 0.6 Beta)

## Pobieranie

Gotowe wersje Bug Browser dla Windows znajdziesz w zakładce Releases.
